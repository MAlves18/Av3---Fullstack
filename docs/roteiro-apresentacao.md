# Roteiro sugerido para demonstração da AV3

1. Apresentar a pergunta norteadora e os dois territórios.
2. Mostrar o fluxo IBGE/IPEA/EPE → ETL → Supabase/PostgreSQL → React → Vercel.
3. Demonstrar a visão geral e informar fonte/ano dos indicadores.
4. Comparar os territórios apenas nos indicadores com unidade, período e escala compatíveis.
5. Abrir o mapa e explicar a origem da malha territorial.
6. Mostrar a análise energética e deixar explícito quando o dado for estadual.
7. Explicar classificação, metodologia, limitações e próximos dados necessários para medir vulnerabilidade energética familiar diretamente.
8. Mostrar repositório, commits, banco Supabase e URL publicada.

# Redesign visual — referência Carbolytics

A interface recebeu uma direção visual inspirada na abordagem experimental e investigativa de Carbolytics: visualização de dados como um campo de relações, linguagem gráfica editorial, sinais em movimento e maior contraste entre informação e visualização.

## Alterações
- Tema escuro grafite com acentos verde-lima e coral.
- Nova abertura editorial na Visão geral.
- Campo gráfico SVG com nós e conexões animadas, gerado localmente.
- Sidebar, filtros, cartões, tabelas e painéis redesenhados.
- Tipografia de interface e monoespaçada para metadados.
- Ajustes de responsividade para telas menores.
- Cores das séries dos gráficos alinhadas à nova identidade.

## Integridade dos dados
O campo de nós é uma ilustração conceitual da relação entre território, infraestrutura e condições de vida. Não é uma rede geográfica, não representa tráfego em tempo real e não cria indicadores novos. Os valores e visualizações continuam dependendo dos registros retornados pelo Supabase.

## Referência
Carbolytics, projeto de Joana Moll sobre os custos ambientais do rastreamento online: https://carbolytics.org/
